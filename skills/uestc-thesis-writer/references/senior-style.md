# 师兄样本的风格参考

材料：用户提供的 tutorial.md《基于环境感知的 MIMO 信号检测与定位定姿算法研究》及《谭思源毕业论文20260320.md》。原文不随技能分发；这些观察不是导师直接批示，也不代表样本全部符合校规。

| 观察位置 | 可迁移写法 | 不迁移内容 |
| --- | --- | --- |
| tutorial 第3.5节 | 参数集中交代，然后分验证对象逐步分析 | 场景、算法、全部数值、图中结论 |
| tutorial 第3章结构 | 模型、模块、方法整合、验证依次推进 | 固定节数与研究方向 |
| 谭思源第3.5节至4.1节 | 章末交代已有方法的输出，下一章从剩余限制引出后续问题 | 特定模型名称、性能和因果结论 |
| 谭思源第3.4节 | 按条件和对比问题分组讨论，关注趋势变化 | 未由用户数据验证的泛化解释 |

使用方法：识别用户章节的论证任务，选择相近的组织方式，再用用户自己的事实重建段落。不要对原句逐词替换；不移植两篇论文的主题。样本存在“我们”、重复过渡、抽取断词及图像占位，不视为规范。

风格迁移检查：是否只有段落功能相似，表述与材料均来自用户研究？是否保持专业术语和真实条件？是否为了模仿把不同研究强行分成同样章节？若是，应重构。
