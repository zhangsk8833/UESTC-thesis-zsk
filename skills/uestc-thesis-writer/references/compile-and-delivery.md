# 编译与交付

先检查 main.tex、metadata.tex、图片、bib 和实际工具版本。上游当前要求 XeLaTeX 与 TeX Live 2024 或以上；不要将旧 2020 的运行成功当完整兼容证明。显式选用兼容环境，避免修改系统 PATH 或覆盖旧安装。

运行 compile_thesis.py，保存各轮日志，检查最终引用是否解析、书目是否生成。符号表/缩略词表启用时根据上游流程运行 makeindex 并增加必要编译轮次。编译脚本检测到模板旧工具链、缺文件或 LaTeX 错误应失败，不能只看 PDF 是否存在。

静态检查和渲染并行互补：检查重复标签、缺引用、占位内容、身份信息、元数据和正文一致性；查看封面、中英文扉页、声明、摘要、目录、典型正文、图表公式页、文献和末页。

学校具体条款见 school-profile/source-map.md。章节标题换页和段距、题注行数、页码及留白依赖渲染。中间页较大空白须追查浮动体、长表或强制分页，不通过全局缩字号掩盖。

盲审仅在用户需要时生成独立副本，按适用要求处理姓名、学号、导师、致谢、成果和 PDF 元数据；不能删除应有引用，也不能保证所有隐性身份线索均自动识别。保留正式版。

定稿需清除所有待补标记、演示内容、错误引用和未确认结论。输出时注明验证环境、覆盖范围及真实限制，不能称“学校审核通过”。Word 转换后的编辑应回到 LaTeX 同步，再重新导出。
