# 摘要与必要英文摘要

中文摘要按学校要求一般不超过800字且不超过1页，关键词3～5个。以研究目的、方法、结果、结论为主，避免逐章介绍。只概括已完成研究，不引入正文没有的数值。英文摘要内容对应中文，用Thesis称学位论文，关键词按规范。不要为了“带数字”编造指标；缺数据先保留待补状态。最终逐项对照贡献、条件和结果。

写前检查：本节目的、输入证据、前后关系是否清楚。写后检查：事实、引用、条件、符号与主张是否一致。材料不足的地方列具体问题，不用流畅文字掩盖。

## 写作顺序与内容核对
在主要研究内容与结果稳定后写摘要。以有限篇幅交代问题和目的、真实完成的方法/工作、最有代表性的结果及结论。不把全文每章各摘一句串起来，也不在摘要首次提出正文没有的创新主张。

主要结果可写量化信息，但必须与正文的指标、基线和测试条件一致。摘要空间不足时选最关键证据，不能只保留最好看的百分比而删掉决定其含义的条件。未得到精确数值时使用有依据的定性描述，不编数值。

中文摘要按学校篇幅约束核对，关键词3–5个、分号分隔；词语应能代表研究对象和主要方法，不随意加入热门术语。英文摘要与中文逐项对齐研究事实、限定条件、结果和结论，语言可自然调整；英文标题和关键词统一大小写与术语。

检查读者仅凭摘要能否知道研究的具体对象、为何研究、完成了什么、得到什么。避免题目中对象在摘要被缩写得无法识别。跨领域缩写首次解释；无必要不堆公式、引用、模块编号或自造简称。
