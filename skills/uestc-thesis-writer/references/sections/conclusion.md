# 结论与展望

直接回答研究问题，概括本人工作和已有证据支持的价值。与他人成果明确区分；不逐章复述，不新增方法或实验。说明真实限制，展望提出可执行后续方向而非泛泛“进一步提升”。局限不必抹掉已有贡献，贡献也不能掩盖未验证条件。章末小结只总结该章职责并自然引到后续。

写前检查：本节目的、输入证据、前后关系是否清楚。写后检查：事实、引用、条件、符号与主张是否一致。材料不足的地方列具体问题，不用流畅文字掩盖。

## 总结与展望的边界
沿研究问题回顾已经得到的结论，说明其适用范围和证据来源，避免再次描述全部算法步骤。主要贡献与绪论对应，但用完成后的证据重新表述，不原样复制贡献清单。没有做过的实验、系统部署或理论证明不能在此突然出现。

局限写成可理解的条件和影响：数据覆盖、模型假设、复杂度、环境约束、工程实现或评价范围。不要用无关紧要的措辞问题替代实质限制，也不要笼统否定整个研究。

展望从实际局限引出具体问题和可能方向，区分已经在做的工作与建议。可以提出路线，但不承诺没有依据的性能，也不把未完成内容当成本论文贡献。结论通常不引入新图表、公式和引用；确有需要时核查学校与学院要求，不能绝对禁用。
