# 绪论与研究现状

从具体场景说明研究必要性，给出已有方法的分类、假设和局限，推到本论文实际问题。相关工作要综合比较而非堆题名。贡献必须对应后文章节及证据；区分工程实现、方法创新和实验发现。结构介绍简短，不提前讲全部算法步骤。新术语在读者需要时解释，不要求读者预先理解内部模块。

写前检查：本节目的、输入证据、前后关系是否清楚。写后检查：事实、引用、条件、符号与主张是否一致。材料不足的地方列具体问题，不用流畅文字掩盖。

## 从背景收敛到研究问题
背景先限定场景、对象与约束，再说明已有方法在这些条件下仍存在什么问题。避免从“信息技术迅猛发展”跨越数段才出现研究对象。工程应用价值应落到可说明的成本、可用性、精度或约束，不用宏观口号替代技术动机。

研究现状不是按年份抄文献摘要。先选择与本文问题相关的分类轴，如模型假设、可用信息、求解方式或应用条件；每类说明代表工作、解决了什么、仍有什么边界。确保分类互不矛盾，不把不同层级的分类混在同一标题中。关键不足要有证据，不能泛称“现有方法均不能”。

通过“场景约束—已有办法—未解决问题—本文研究范围”收敛。只有后文真实解决并验证的问题才列为本文主要工作；把使用了某工具与提出新方法区分开。贡献列表在中文学位论文中可以使用，但每项应具体且与章节/证据对应。

章节安排描述功能与依赖关系，避免复制目录或预先宣称所有方法都效果卓越。若问题和贡献在写实验后变化，回来同步绪论与摘要，不让开篇承诺超过最终完成范围。
