# 审稿人与导师双视角自检清单（Audit Checklist）

在完成任意章节撰写或全稿定稿前，按以下清单逐项核查：

## A. 逻辑与论证闭环
- [ ] **章引言承接**：第 3、4 章的“X.1 本章引言”是否明确指出了上一章的遗留问题或递进关系？
- [ ] **主张前置（Claim-Forward）**：是否避免在段首堆砌“虽然存在一定局限”“遗憾的是”等自我削弱表述？限制条件应放在客观分析段，而非先否定自己。
- [ ] **综述比较轴**：第 1 章国内外研究现状的同级子节是否建立了统一比较维度，且每节末尾均收束到“现有不足与本文动机”？
- [ ] **跨章闭合**：第 1 章列出的主要贡献点、各章“本章小结”与最后一章“全文总结”是否一一对应、口径一致？

## B. 导师偏好与防 AI 核查
- [ ] **人称检查**：全文是否彻底清除了“我们”“笔者”？
- [ ] **禁用词检查**：是否清除了“显著提升”“首次提出”“填补空白”“革命性”“不仅如此”“总而言之”等词？
- [ ] **指代消歧**：多对象上下文中是否已将模糊的“它/它们/前者/后者”替换为具体名词？
- [ ] **物理机制落地**：是否避免了只谈“映射/耦合/赋能”而未写明具体输入、约束与输出变量？

## C. 电子科大规范核查
- [ ] **字数红线**：中文摘要 ≤ 800 字，致谢 ≤ 800 字；英文摘要使用 `Thesis` 而非 `This paper`。
- [ ] **章节规范**：各研究章末尾均有“本章小结”；所有标题无标点符号、不超一行。
- [ ] **图表与公式**：所有图、表、公式在正文紧邻前文均有提示（“如图 X-Y 所示”“见式 (X-Y)”）；公式后有“式中”解释。
- [ ] **参考文献**：无正文未引用的虚列文献；作句子成分时不用上标（`\textcite` 或手动非上标格式）。
