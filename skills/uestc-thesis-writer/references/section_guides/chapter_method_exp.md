# 核心方法与仿真实验章节撰写指南（第 3、4 章）

## 1. 标准节结构（对标课题组师兄范式）

1. **X.1 本章引言**：2~4 句，承接上一章遗留瓶颈，点明本章研究对象与整体技术路线。
2. **X.2 系统模型与问题描述**：
   - 先交代系统架构图引导语与物理场景假设；
   - 给出信号/数据模型公式，紧随“式中，”解释所有符号维度与物理含义；
   - 形式化定义优化目标或待求解问题。
3. **X.3 所提算法/方法设计**：
   - 按“总体框架 → 核心模块推导 → 算法流程（伪代码 `algorithm2e`）→ 计算复杂度分析（$\mathcal{O}(\cdot)$）”展开；
   - 每步推导必须写明所依据的假设或数学性质，禁止“易得”“显然”。
4. **X.4 仿真/实验结果与分析**：
   - **X.4.1 参数配置与对比基线**：用三线表汇总核心超参数；用紧凑列表说明各对比基线原理与设置；
   - **X.4.2 消融与主对比实验**：严格按“引图提问 → 关键工作点定量读数 → 机理解释与局限/性能差距归因”三段式撰写。
5. **X.5 本章小结**：三句收束（问题与模型 → 核心方法 → 实验主要结论及与下一章衔接）。
