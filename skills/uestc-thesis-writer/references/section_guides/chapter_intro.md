# 第一章 绪论撰写指南

## 1. 漏斗式结构与写作要点

1. **1.1 本章引言**：简短 1~2 句交代本章组织结构（研究背景、国内外现状、主要贡献与全文安排）。
2. **1.2 研究背景与意义**：
   - 由宏观应用场景切入，迅速收敛到核心物理/工程矛盾（如高移动性下的信道老化、有限反馈开销、先验失配等）；
   - 阐明解决该矛盾的理论意义与工程应用价值（忌空泛口号）。
3. **1.3 国内外研究现状**：
   - 按研究子方向划分为 2~3 个同级小节；
   - **统一比较轴（导师硬性要求）**：各子节采用统一的评价维度（如建模精度、计算复杂度、对先验/维度变化的适应性）梳理代表性文献，**严禁写成“张三做了A，李四做了B”的流水账**；
   - 每小节末尾必须收束到当前方法的共性不足，在 `1.3.末` 引出“本文研究动机与关键难点”。
4. **1.4 本文主要贡献与结构安排**：
   - 分条列出 2~3 项实质性工作贡献（与第 3、4 章严格对应，使用“提出了一种……方法”而非“首次提出/国际领先”）；
   - 按“第一章……第五章……”简要说明各章内容，忌与摘要逐字重复。
