# 论文撰写顺序与信息来源边界规范

## 一、“先做后写、由内向外”推荐写作顺序

1. **第 1 步：核心工作章（第 3 章、第 4 章）**
   - 先基于用户的仿真/工程代码、实验日志与结果图，固化数学符号体系、系统模型、算法流程与实验对比分析；
   - 确保每一张图、每一张表都有明确的问题导向与精确数值支撑。
2. **第 2 步：理论基础章（第 2 章）**
   - 仅保留第 3、4 章真正用到的基础理论与数学工具（如信道模型、基础优化/网络原理），做到符号与后续章节完全一致，避免大段抄书式堆砌。
3. **第 3 步：第一章 绪论**
   - 在核心工作已定稿的前提下，提炼研究背景与痛点，围绕自己真正解决的瓶颈组织国内外研究现状（建立统一比较轴），自然引出本文主要贡献与结构安排。
4. **第 4 步：结论与中英文摘要**
   - 依据第 3、4 章实测数据凝练全文总结与局限性展望，最后撰写中文摘要（≤ 800 字）与英文 `ABSTRACT`。

## 二、四类信息来源严格区分（防幻觉护栏）

| 信息类别 | 处理方式 |
| :--- | :--- |
| **1. 原文/代码/实验日志已有事实** | 直接引用，保持参数名称、单位、数值与代码/日志完全一致。 |
| **2. 用户在对话中确认的补充信息** | 可直接写入正文，但需与前后文符号统一。 |
| **3. 合理机制推断** | 仅用于解释已观测到的实验趋势（如“推测该性能差距主要源于……”），不得写成已通过实验消融证明的既定事实。 |
| **4. 建议性扩展（如待补实验/待查文献）** | **不得直接冒充正文事实**，统一以 `% [待补充: ...]` 注释形式标出，交由用户确认或补充。 |
