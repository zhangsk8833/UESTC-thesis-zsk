# 导师偏好及适用范围

主要来源为 Digital-Mentor 的 `ieee_writer/knowledge_base/学术写作规范.md`、`style_profile.md` 和 `memory.md`；本档案是中文学位论文适配，不是导师亲自确认的逐条批示。上游对应文件链接见末尾。规则不覆盖学校硬性条款或研究事实。

| 编号 | 中文论文执行规则 | 上游位置 | 强度与边界 |
| --- | --- | --- | --- |
| M01 | 写清哪个对象受什么条件影响，输入、关系、处理和输出分别是什么 | 学术规范 1.1 | 论证正确性要求；不能用“映射关系”掩盖机制 |
| M02 | 性能、泛化与贡献限定到实际测试范围 | 1.2 | 不因追求语气坚定扩大结论 |
| M03 | 句段之间具有清楚语义关系 | 1.3；风格档案 | 不强制重复上一句末尾关键词，不虚构因果 |
| M04 | 一句承担一个主要判断，复杂对象与限制对应清楚 | 1.4 | 可保留必要长句，不按字数机械切割 |
| M05 | 同一概念使用统一术语，缩写首次定义 | 1.5；memory | 不为“去 AI”换技术同义词；不移植 CKM 术语到无关研究 |
| M06 | 删除重复信息，但保留决定结论的条件 | 1.6 | 限制条件不作为冗余删除 |
| M07 | 模块命名体现主体、附属关系及真正作用 | 1.7、1.8 | 摘要中不预设读者懂自定义模块和离散化对象 |
| M08 | 文献分类有一致比较轴，由已知不足推出研究问题 | 2.1、2.2 | 不采用 WCL 固定篇幅；中文论文允许合理列出主要工作 |
| M09 | 模型交代假设、输入、待求量及目标；只引入必要符号 | 3.1、3.2 | 模型本身是贡献时充分展开，不限制半页到一页 |
| M10 | 符号、维度、运算首次使用时就近解释 | 3.3～3.6 | 字体依据物理/数学含义；集合和张量不能混淆 |
| M11 | 先问题与设计直觉，再模块步骤，最后整体算法及代价 | 3.7 | 根据真实数据流组织，不能杜撰设计动机 |
| M12 | 关键推导交代前提、替换和数学性质 | 3.8 | 常规计算可略，决定结论的假设不可省 |
| M13 | 横向基线与纵向消融各有问题指向 | 4.1 | 无法做标准基线时说明原因，不能用消融冒充充分比较 |
| M14 | 图表分析交代内容、代表趋势/数值、解释或归纳 | 4.2 | 不是每图固定三段；机制推测需标清与证据关系 |
| M15 | 克制、具体，减少商业隐喻和模糊代词 | style_profile | 有严格证据时可用“证明”；“显著”不是无条件禁词 |

中文人称来源：学校规范 2.1 要求避免“我们”；不是从上游英文 We propose 反推所得。英文期刊投稿、magazine 图题放参数、短文不列贡献列表等均不纳入技能。

### 审校例子（仅语言示例，无实验事实）
不充分：“该模块充分利用复杂关系，大幅提高鲁棒性。”
改写前先问材料：模块输入是什么、用了哪种关系、在哪个干扰条件比较了哪个指标？
有证据才写成：“该模块依据〔关系〕估计〔变量〕，在〔测试条件〕下相较〔基线〕降低〔已测指标〕。”缺证处保留为问题，不能填入想象数字。

新增规则需记录：作者确认日期、原始批注位置、适用章节/情形、例外、示例。导师针对某图要求改写，不自动代表全论文都用同一句型。
