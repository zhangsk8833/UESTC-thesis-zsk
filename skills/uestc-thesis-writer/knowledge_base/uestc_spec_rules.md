# 电子科技大学专业硕士学位论文撰写规范硬性规则

> 依据《电子科技大学研究生学位论文撰写规范-适用于中国学生》整理，作为论文写作与 `check_uestc_tex.py` 自动化核查的权威依据。

## 1. 专业硕士（promaster）基本要求

- **封面颜色**：专业学位硕士为淡黄色（模板中使用 `\documentclass[promaster]{DissertUESTC}` 自动匹配）。
- **论文题目**：简明反映核心内容，**一般不超过 25 个汉字**，避免不常用缩略词、字符、代号或公式。
- **专业学位类别**：参照研究生管理信息系统登记，如 `0854 电子信息`、`0855 机械`、`0856 材料与化工` 等；学术与专业类别中英文名称须严格对照学校规范附录。
- **指导教师**：封面仅填写 1 名责任导师；若有联合指导教师，可在中、英文扉页相应位置填写。

## 2. 文档结构与字数红线

| 部分 | 必需内容与硬性规范 |
| :--- | :--- |
| **前置部分** | 封面、中英文扉页、独创性声明与论文使用授权、中文摘要、英文摘要、目录（从第一章开始，不含前置部分）、（可选）图目录/表目录/主要符号表/缩略词表 |
| **中文摘要** | 独立成文，含研究目的、方法、结果与结论（重点在结果和结论）；**一般不超过 800 字，最多不超过 1 页**；忌用图、表、公式；忌写“第一章……第二章……”提纲式陈述；**关键词 3~5 个**（分号隔开） |
| **英文摘要** | 标题 `ABSTRACT` 全大写；内容与中文一致；硕士论文译为 **`Thesis`**，**严禁使用 `This paper`**；英文关键词与中文对应，**每个单词首字母大写** |
| **主体部分** | 第一章绪论（忌与摘要雷同）；中间各章结尾**必须有“本章小结”**；最后一章结论（严禁与各章小结简单重复，无充分证据**禁用“首次”“领先”“填补空白”**等表述） |
| **致谢** | **一般不超过 800 字，最多不超过 1 页** |
| **参考文献** | 仅列正文实际引用的文献，**严禁虚列未引用文献**；严格执行 **GB/T 7714-2015** 顺序编码制；正文中一般为上标 `[1]`，作句子成分时不上标（如“由文献[8, 10-13]可知”）；不得标注在各级章节标题处（引用的图表标题除外） |
| **成果列表** | 仅列攻读学位期间与论文密切相关的成果；**本人姓名加粗**；超过 5 人可按“本人姓名(本人排名次序/总人数)”简写 |

## 3. 语言、术语与排版细节

- **术语与缩略词**：首次出现较长词组时使用“中文全称（英文全称, 缩写）”或“中文全称（英文全称）”，例如：`智能反射面（Reconfigurable Intelligent Surface, RIS）`，后文统一使用缩写；缩略词表按英文缩写字母顺序排列。
- **标题规范**：各章标题（`第一章 绪论`）不超过一行，**标题中不加标点符号**，尽量不用英文缩写词；正文层次一般至三级（`1.1.1`），最多四级（`1.1.1.1`）。
- **表与图规范**：
  - 分章连续编号（`图2-5`、`表3-2`）；紧邻前文必须有提示（“如图2-5所示”“见表3-2”）；
  - 表格采用**三线表**（上下边线 1.5 磅，表内线 0.75 磅），不用“同上”“同左”，空白代表未测/无此项，“…”代表未发现，“0”代表确为零；跨页续表须重复表头并在表题末尾标注`（续）`；
  - 图中文字大小与图题（五号）一致，非直接引用的图坐标轴与说明文字统一使用中文。
- **量和单位**：执行 GB 3100~3102，量符号斜体、单位正体，量与单位间用斜线隔开（如 $I/\mathrm{A}$、$\rho/\mathrm{kg\cdot m^{-3}}$）；非中文数值与单位间空 1 个半角字符（如 `1 m`）。
