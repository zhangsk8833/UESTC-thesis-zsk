# 导师学术写作偏好与审稿规范（核心权重约束）

> 本文件融合课题组开源导师规范 [Digital-Mentor](https://github.com/Gavin-Jiang-97/Digital-Mentor) 中的 `style_profile.md` 与 `学术写作规范.md`，在撰写与润色电子科技大学专业硕士学位论文时拥有**最高优先级**。

## 1. 核心写作 DNA（Tone & Logic）

1. **语态与视角**：
   - 全文保持正式、严谨、克制的工科学术语态，**严禁使用“我们”“笔者”**等非唯一作者人称；统一使用“本文”“本节”“本章”或客观技术主语（如“所提算法”“该模型”）。
   - 保持客观陈述与边界意识，区分**确定性实验结果**与**合理机制推断**。
2. **句间与段间逻辑（Sentence-by-Sentence Handoff）**：
   - 段落首句应独立成立，直接点明本段核心主张或要解决的问题。
   - 相邻句子之间必须形成显式语义承接：用上一句末尾的核心概念/矛盾引出下一句（如“该失配导致……”“针对上述计算瓶颈，本节引入……”“这一权衡在低信噪比条件下尤为明显”）。
   - 拒绝断层式罗列或空洞过渡，所有因果、对比、递推关系必须写出中间机制。
3. **准确对应物理机制与操作对象**：
   - 严禁使用模糊、空泛的抽象名词代替具体技术过程（例如避免只说“利用了某种映射关系”，必须写明**利用了什么输入数据、通过什么数学/物理关系、估计或重构了什么目标变量**）。
   - 命名对比项或技术类别时，使用直接反映技术关系的准确名称；同类方法综述必须建立统一的**高层比较轴**（如计算复杂度、先验依赖、适用场景），并在各子节开头点明该比较轴。
4. **消除指代歧义**：
   - 当上下文出现两个及以上技术对象时，**禁止使用孤立的“它”“它们”“该现象”“前者/后者”**，直接重复具体对象名称（如“该预测器”“加权最小均方误差算法”）。

## 2. 严格禁用词与规避风格表

| 类别 | 禁用或严控表达 | 替代方案 |
| :--- | :--- | :--- |
| **夸张形容词/副词** | 显著提升、极大增强、革命性、颠覆性、前所未有、极其重要、完美解决、卓越表现 | 给出具体量化对比（如“在 SNR = 10 dB 时将 NMSE 降低 2.1 dB”“较基线方案降低约 16% 的计算耗时”） |
| **绝对化结论** | 首次提出、填补空白、国际领先、证明了……（用于非严格数学定理时）、保证了…… | “实验结果表明……”“在本文仿真配置下……”“验证了所提方法在……方面的有效性” |
| **口语化与商业隐喻** | 生态系统、杀手锏、游戏规则改变者、痛点、赋能（过度泛化时）、赛道、抓手 | 直接使用通信/计算机/信号处理标准领域术语 |
| **高频 AI 味连接词** | 不仅如此、值得注意的是、总而言之、综上所述（每章末重复堆砌）、毫无疑问、显而易见 | 根据实际逻辑改用具体因果或转折词（“进一步地”“然而”“相比之下”“由此可见”）或直接以主语起句 |
| **模糊笼统修饰** | 有效、先进、复杂环境（未定义具体非理想因素时）、良好性能 | 指明具体指标或物理条件（“在高速移动多普勒频移条件下”“在非视距多径散射环境中”） |

## 3. 系统模型与算法章节硬性准则

1. **先假设后建模**：明确交代系统假设与适用边界（如信道准静态假设、循环前缀长度假设、已知量与待估量划分）。
2. **符号与数学字体规范**：
   - 向量用小写粗体（如 $\mathbf{h}$），矩阵用大写粗体（如 $\mathbf{H}$），集合或张量用花体（如 $\mathcal{H}$）；
   - 表示词语或缩写的上/下标用正体（如 $\mathbf{H}_{\mathrm{d}}$、$\mathrm{SNR}$），表示索引或变量的下标用斜体（如 $h_i$、$k$）；
   - 首次出现的专有数学运算符（如 Kronecker 积 $\otimes$、Hadamard 积 $\odot$、Khatri-Rao 积 $\odot_c$）必须在紧邻正文处明确解释。
3. **推导完整无跳跃**：禁止仅写“经简化可得”“易得”，必须简要说明所依据的数学性质或独立性假设（如“利用导频矩阵的正交性”“基于各径复增益互不相关的假设”）。
4. **公式后“式中”规范**：独立编号公式后另起一段顶格写“式中，……”，按从左到右、从上到下的顺序解释符号物理含义及维度，用分号隔开。

## 4. 仿真与实验章节写作准则

1. **先配置、再基线、后分析**：
   - 节首集中交代仿真平台、信道/数据集参数（建议配参数汇总表）与全部对比基线（简述各基线原理与设置）；
   - 不在图题中堆砌冗长仿真参数，图题保持简洁（如“不同信噪比下的信道估计 NMSE 对比”）。
2. **三段式图/表解读法**：
   - **引图提问**：说明该图/表旨在验证什么问题或对比什么条件；
   - **定量读数**：给出关键工作点下的精确数值对比（禁止只说“A 优于 B”）；
   - **机理解释与折衷分析**：结合物理意义或网络结构解释“为什么会出现该趋势/交叉点/性能差距”，客观分析局限性（如与理论极限 CRLB 存在差距的原因）。
