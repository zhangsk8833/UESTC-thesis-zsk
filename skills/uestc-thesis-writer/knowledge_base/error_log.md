# 个人写作错题本与导师批注记忆库（Error Log）

> 本文件用于持续沉淀导师审阅批注、组会修改意见及个人高频笔误。每次收到导师新反馈后，将问题模式与修正对策追加至本文件末尾，后续撰写与审校将自动避坑。

## 已内置初始规则（源自课题组共性反馈）

1. **摘要/结论混淆**：摘要侧重研究目的、核心方法与关键定量结果；结论侧重总体贡献总结、机制认识与局限性展望，不得将摘要或各章小结直接复制为结论。
2. **符号前后不一致**：同一物理量在不同章节必须使用完全相同的字母与上下标格式（建议在 `chapters/acronyms.tex` 中集中维护主要符号表）。
3. **图表孤立出现**：任何图、表、公式在正文中出现前，必须先有文字引导句（如“如图 3-2 所示”），不得在标题后直接放置图/表/公式。
4. **对比实验公平性交代不足**：引入多种对比基线时，必须显式说明所有方法是否在同一数据集、同一超参数预算或同一信道环境下评估。
