# 课题组师兄论文行文风格与结构范式指南

> 本文件提炼自课题组两位师兄的硕士学位论文文本结构与表达习惯，**仅用于模仿其章节组织、学术语态、公式衔接与实验分析节奏**；具体研究方向、算法名称与实验内容完全以用户自身课题为准。

## 1. 全文标准章节骨架

两位师兄论文均严格遵循电子科技大学工科硕士论文的经典五章或六章结构：

1. **第一章 绪论**：
   - `1.1 本章引言`（1~2 句点明本章内容）
   - `1.2 研究背景与意义`（宏观应用趋势 → 核心物理/工程瓶颈 → 解决该问题的理论与工程意义）
   - `1.3 国内外研究现状`（按技术演进或子问题分 2~3 个小节综述，每小节末必须有**现有研究不足与本文研究动机**的收束段）
   - `1.4 本文主要贡献与结构安排`（以序号列举 2~3 项创新点，随后按“第一章……第N章……”概述全文章节安排）
2. **第二章 相关原理与技术基础**：
   - `2.1 本章引言`
   - `2.2 ~ 2.X`（系统/信道/基础算法数学原理，为后续核心章统一符号与公式铺垫）
   - `2.末 本章小结`
3. **第三、四（、五）章 核心研究工作（每章对应一个相对独立又前后递进的子课题）**：
   - `X.1 本章引言`（承接上一章的遗留问题或递进关系，引出本章研究目标）
   - `X.2 系统模型与问题描述`（配系统框图、数学模型、目标函数/问题定义）
   - `X.3 所提算法/方法设计`（按“总体框架 → 子模块推导 → 算法伪代码/复杂度分析”展开）
   - `X.4 仿真/实验结果与分析`（参数配置表 → 对比基线列表 → 消融实验 → 主对比实验 → 跨场景/鲁棒性分析）
   - `X.5 本章小结`（客观总结本章方法与主要实验结论）
4. **最后一章 全文总结与展望**：
   - `N.1 全文总结`（按贡献点分条凝练，忌直接复制各章小结或写成流水账）
   - `N.2 未来研究方向`（围绕本文局限性提出 2~3 条具体可行的后续改进方向）

## 2. 高频标准学术句式库（可直接迁移至任意工科方向）

### 2.1 章引言与节过渡
- “针对第 X 章中……的局限性，本章进一步将研究拓展至……场景，重点解决……问题。”
- “为便于后续推导与符号统一，本节首先建立……模型，并给出……的形式化描述。”
- “基于上述分析，仅依赖单一……难以兼顾……与……之间的折衷。为此，本节提出一种基于……的……方法。”

### 2.2 公式引入与推导衔接
- “……的接收信号（或状态转移）模型可表示为如下形式：”
- “其中，$\mathbf{X} \in \mathbb{C}^{M \times N}$ 表示……；$\mathbf{n}$ 表示……。”（紧跟公式给出符号说明，无需在正文中重复解释已在表格中列出的常规参数）
- “将式 (X-Y) 代入式 (X-Z) 并结合……性质，可得关于待估参数……的等价优化问题：”
- “上述求解过程的主要计算开销集中在……，其总体计算复杂度约为 $\mathcal{O}(\cdot)$。”

### 2.3 仿真分析与归因
- “为保证对比的公平性，除……外，其余链路模块与训练/仿真超参数均保持一致。”
- “如图 X-Y 所示，随着……的增大，所有对比方案的……均呈现……趋势。具体而言，在……条件下，所提方法相较于基线 A 和基线 B 分别取得了……和……的性能增益。”
- “该现象的原因可从以下两个层面解释：其一，……；其二，……。”
- “从图中仍可观察到所提方法与理想性能上界之间存在约……的差距，这主要源于……。”

### 2.4 本章小结（禁止空话，三句收束）
- 第一句：交代本章针对的具体问题与所构建的模型/框架；
- 第二句：概括所提出的核心方法与关键技术手段；
- 第三句：总结数值仿真/实验验证的核心结论，并自然过渡至下一章（若为最后一研究章，则收束为对全链路的作用）。
