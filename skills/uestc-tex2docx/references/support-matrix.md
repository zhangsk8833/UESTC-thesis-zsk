# 转换支持范围

| 对象 | 当前处理 | 验收边界 |
| --- | --- | --- |
| input/include、中文正文 | 递归展开、保留顺序、哈希清单 | 不执行 TeX，条件编译/includeonly 报错 |
| 章及 2–4 级标题 | 自动中文章号和层级号 | 深于4级报错；自定义无编号标题需样本审查 |
| 中英文摘要、目录、致谢、文献 | 独立分节；目录为 Word 域 | 必须刷新域和复核页码 |
| 行内数学、equation | OMML；equation 按章编号 | 样例覆盖矩阵、求和分式、分段函数；逐式比对 |
| 无编号展示数学、equation* | 不自动增编号 | 有 label 时拒绝歧义 |
| label/ref/eqref | 跨章解析为静态文字编号 | 编辑 Word 后不自动重排引用 |
| 普通 figure、PNG/JPEG | 原图、图号和题注 | 检查尺寸、分辨率和题注位置 |
| PDF 插图 | 首页面栅格化，216 dpi，有报告警告 | 多页 PDF 须拆分；对细线图需更高质量替代 |
| SVG | 交 Pandoc/Word 处理 | 未纳入当前图像回归，不能承诺兼容 |
| 普通 tabular/booktabs | Word 表格、三线、重复首行 | 复杂合并/跨页续表未自动验收 |
| cite + bibliography | citeproc、GB/T 7714—2015 数字顺序制 | 与 LaTeX bst 不保证逐字符一致，按校规核对每种文献类型 |
| 有序/无序列表、脚注 | Word 原生结构 | 带圈号、按页重启、小五9 pt与悬挂缩进已设置；多页脚注需终稿专项检查 |
| align/gather/multline/subequations、手动 tag | 明确拒绝，等待适配 | 不能拆行丢条件或错误合并编号 |
| algorithm/algorithmic、TikZ、subfigure、longtable、附录 | 明确拒绝，等待适配 | 提供小样后实现语义适配并测试；不静默忽略 |
| 其他未知 raw TeX | 报错并定位片段 | 只有证明其纯布局作用后才允许映射为空 |

支持不等于全自动合规。长题名、长图题、跨页表、宽公式、不同字体、版本差异必须在最终文档逐页检查。电子版默认使用条件域实现奇偶页眉，避免 Word 重启页码时强制补空白页；所有章仍使用下一页分节。`--print-layout` 使用 Word 原生奇偶页眉，但完整打印插页仍需按学校规则检查。电子版任何空白页都视为失败，不能只删除 PDF 页来伪装修复 DOCX。
